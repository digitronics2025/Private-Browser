# Desktop release highlights

Add one `short-descriptive-name.txt` file for a desktop change people can see
or use. Write one short plain-text paragraph of up to 350 characters. The
publisher reads new files from the candidate revision and compares with the
active release, so highlights from a delayed release carry forward. The app
and download page share that text.

Keep earlier files in the archive. The [changelog](../../CHANGELOG.md)
describes older versions and links to the public release history.
