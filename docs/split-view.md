# Split view

With a regular page active, right-click the second tab and choose **Show beside
active tab**. Click inside either pane to focus it, or use **Focus other pane**
in the tab strip. The address bar and shortcuts follow the selected pane. Use
**End split view** to return to one pane.

Both pages must belong to the same unlocked Account Space. They use its existing
partition. A menu, dialog or permission prompt hides both views. Split view
pauses when the window is too narrow or enters full screen. Returning to one
of the paired tabs restores the split during the same browser session.

Closing a paired tab, navigating to Home or a protected URL, opening DevTools,
or lending a paired tab ends split view. After restarting, the browser restores
the individual tabs through the normal tab restore flow.
