# Private Browser Bridge

Private companion extension for Private Browser. Install the packaged VSIX, run
**Private Browser: Pair with Browser**, and enter the one-time code shown in the
browser's Developer panel. The extension is intentionally not published to the
VS Code Marketplace.

Commands, tests, file navigation, and edits are limited to trusted, explicitly
approved local workspaces. Pairing keys are stored through VS Code SecretStorage.
